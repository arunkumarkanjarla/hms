Mobile screen and user-experience principles

The mobile app should make high-frequency actions fast and readable, while leaving dense administration to the web application.

What is better on web?

Platform administrationBulk hospital onboarding, global configuration and access policy
Advanced analyticsLarge reports, cross-facility analysis and data visualisation
Complex financeReconciliation, payer settlements and long claim workflows
Bulk operationsMass import/export, workforce planning and audit investigations

Mobile interaction design rules

One-thumb navigation4 main bottom destinations
Readable hierarchyShort headings, clear status chips
Focused formsOne-column on narrow screens
Search firstFind patient, task or reference quickly
Safe actionsConfirm destructive or high-impact actions
Responsive layoutPhone-first; adapts to wider browser

The included static prototype implements the visual patterns and local interactions, but not the production security or workflow validation behind clinical actions.
