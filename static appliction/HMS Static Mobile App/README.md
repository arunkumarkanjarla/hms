# CareAxis HMS — Static Mobile Application

## Start
Open `index.html` in a browser. Choose a role and continue to its mobile workspace. No server or build tools are required.

## Included workspaces
Patient & Family; System Administrator; Hospital Management; Front Desk; Doctor; Nursing; Emergency Team; Laboratory; Radiology; Pharmacy; Billing & Insurance; IPD & Ward; Operation Theatre; Inventory & Purchase; HR & Payroll; Medical Records.

Each workspace has a phone-first home dashboard, role-specific quick actions, mobile navigation, task records, forms and a menu of all role screens.

## Static interactions
- Role selector routes to the selected workspace; it is not authentication.
- Forms save entries in the current browser's localStorage.
- Search filters visible sample records.
- CSV export downloads saved local entries.
- Sample tasks, names and metrics are illustrative.

## Important
No backend or database is included. Entries are not shared between users or devices. Do not enter real patient information, credentials or use this prototype for real clinical care. A production HMS requires server-side authentication, role and tenant enforcement, audit logging, encrypted data handling, backups and clinical workflow validation.
